# šalinrankas.lt (GitHub Pages)

Static website for news, events, and archive.

## Deploy
- Repository Settings → Pages → Source: **main** branch
- Custom domain: **šalinrankas.lt**
- Root `/` redirects to `/lt/`

## Update content
Edit:
- `data/posts.json` (events + news)
- `data/gallery.json` (archive links)
